# example: React + Highcharts

A minimal app that shows how chartwright is meant to be used: load rows, ask a
question in plain language, render the returned chart-library options.

## Run it

```bash
npm install                       # from the repo root (npm workspaces)
npm run gen:data                  # regenerate the synthetic dataset (optional)
npm run dev                       # http://localhost:5173
```

## What is here

| Path | What it is |
|---|---|
| `data/post-trade.json` | 800 synthetic post-trade records, generated by `scripts/generate-data.mjs` |
| `scripts/generate-data.mjs` | Deterministic generator (fixed seed) — synthetic, no real trades or identifiers |
| `src/data.ts` | Loads the rows and infers column metadata |
| `src/placeholder.ts` | **Step 1 stand-in**: a neutral spec plus a ~40-line executor, returning Highcharts options and the dataset that was plotted |
| `src/components/ChartView.tsx` | Thin imperative wrapper around Highcharts — one options object in, one chart out |

## What Step 2 changes

`src/placeholder.ts` disappears. The call becomes:

```ts
const result = await chartwright.ask({
  query,
  rows,
  llm,                    // your client — the key never reaches this library
  onEvent: renderProgress // optional: stream agent progress to the UI
});
```

`result.options` renders exactly as it does today; `result.dataset`, `result.spec`
and `result.trace` become available for tables, audit and debugging.

## The data is synthetic

Real post-trade data is proprietary and often carries regulated identifiers, so
this example ships a **generated** dataset with a fixed seed. The ISIN-like codes
are random and are not real securities identifiers.
